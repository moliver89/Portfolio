# ESPAÑOL

# 🌐 Portfolio Web - moliverdev.netlify.app

Este es mi portfolio profesional de desarrollo web, creado para presentar mis proyectos, experiencia y habilidades de forma clara, responsiva y accesible.

## 🧾 Descripción

Diseñado con foco en la usabilidad, internacionalización y navegación fluida, este portfolio permite visualizar mis proyectos como tarjetas navegables, adaptando su contenido al idioma del usuario. Está optimizado tanto para desktop como para dispositivos móviles.

## 🚀 Características principales

- Interfaz intuitiva y responsiva adaptable a todos los dispositivos.
- Soporte multilenguaje: Español 🇪🇸 / Inglés 🇬🇧.
- Proyectos presentados como tarjetas interactivas con vistas previas, descripción, tecnologías utilizadas y enlaces a repositorios o demos.
- Secciones claras: Sobre mí, Experiencia, Proyectos y Contacto.
- Enlaces directos a mis redes sociales, e-mail, y descarga de CV en ambos idiomas.

## 🛠️ Stack Tecnológico

- **React** con JSX
- **JavaScript**
- **CSS** modularizado
- **React Context API** para el cambio de idioma
- **Vite** como bundler
- **Netlify** para el despliegue

## 📂 Estructura del proyecto (resumida)

```
src/
│
├── components/
├── contexts/ # Contexto de idioma
├── data/ # Proyectos y experiencia
├── pages/ # AboutMe, Experiencia, Proyectos, Contacto
├── styles/ # Archivos CSS por sección
└── App.jsx
```

# ENGLISH

# 🌐 Portfolio Website - moliverdev.netlify.app

This is my personal portfolio website, built to showcase my web development projects, experience, and technical skills in a clean, responsive, and multilingual format.

## 🧾 Overview

Designed with a strong focus on usability, internationalization, and smooth navigation, this portfolio allows users to browse through project cards, while adapting its content to the user's selected language. Optimized for both desktop and mobile devices.

## 🚀 Key Features

- Intuitive and fully responsive interface.
- Multilingual support: Spanish 🇪🇸 / English 🇬🇧.
- Projects presented as interactive cards with previews, descriptions, tech stack, and links to demos or repos.
- Clear sections: About Me, Experience, Projects, and Contact.
- Direct links to my social media, e-mail, and downloadable CVs in both languages.

## 🛠️ Tech Stack

- **React** with JSX
- **JavaScript** / **TypeScript**
- **Modular CSS**
- **React Context API** for language switching
- **Vite** as bundler
- **Netlify** for deployment

## 📂 Project Structure (brief)

```
src/
│
├── components/
├── contexts/ # Language context
├── data/ # Projects and experience data
├── pages/ # AboutMe, Experience, Projects, Contact
├── styles/ # CSS files by section
└── App.jsx
```
